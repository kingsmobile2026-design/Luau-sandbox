Roblox Buffer / bit32 Sandbox

난독화 코드 분석용 API 모킹 · 코드 실행은 격리된 브라우저 iframe에서만 수행 · 서버에서는 입력 코드를 실행하지 않습니다.

1. 코드 입력

지원 대상은 JavaScript로 작성된 분석용 코드입니다. Roblox Luau 전체 런타임이나 Luau 문법을 구현한 것은 아닙니다. API 호출은 아래의 buffer, bit32 모킹 객체를 통해 실행됩니다.

주의: 난독화 코드는 악성 동작을 포함할 수 있습니다. 실행은 별도 sandbox iframe에서 이뤄지며 네트워크 연결 권한을 주지 않지만, 브라우저/런타임 취약점까지 보장해서 막는 보안 경계는 아닙니다. 신뢰할 수 없는 코드는 주 분석 환경과 분리해 사용하세요.

2. 실행 출력

아직 실행하지 않았습니다.

3. 모킹 API 범위

buffer
create(size), fromstring(str), tostring(buf), len(buf), copy(dst,src,dstOffset,srcOffset,count), fill(buf,value,offset,count)
정수: readu8/readi8, readu16/readi16, readu32/readi32, writeu8/writei8, writeu16/writei16, writeu32/writei32
부동소수: readf32/readf64, writef32/writef64 (little-endian)

bit32
band, bor, bxor, bnot, btest, lshift, rshift, arshift, lrotate, rrotate, extract, replace, countlz, countrz

4. API 동작 메모

바이트 인덱스는 Roblox buffer와 마찬가지로 0부터 시작합니다. 다중 바이트 정수와 부동소수는 little-endian입니다. 범위를 벗어난 접근, 잘못된 버퍼, 유효하지 않은 비트 필드는 오류를 발생시킵니다. JavaScript의 Number 기반 비트 연산 결과는 32비트 정수로 정규화됩니다. Roblox 엔진과의 완전한 호환성을 보장하려면 대상 함수별로 공식 동작과 비교 테스트가 필요합니다.
